# Townhall security review signoff checklist

Status: In progress

## Required controls

- Token TTL between 1-5 minutes
- Membership + role check on every token mint
- CORS/origin restrictions for widget hosts
- Endpoint rate-limiting for token/moderation APIs
- Replay protection and revocation path on downgrade
