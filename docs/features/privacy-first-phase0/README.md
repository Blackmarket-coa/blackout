# Phase 0 Implementation Artifacts

This directory contains concrete deliverables for **Phase 0 — Foundations and Threat Modeling** from the privacy-first steganographic messaging roadmap.

## Included deliverables

1. `adr-stack-boundaries.md`
    - Architecture decisions and trust boundary rules.
2. `data-classification-matrix.md`
    - Data classes, storage/transit, retention, and access constraints.
3. `privacy-abuse-friction-requirements.md`
    - Security/privacy invariants and abuse-friction acceptance criteria.
4. `legal-response-playbook.md`
    - Minimal legal operations interface and disclosure boundaries.

## Phase 0 completion checklist

- [x] Stack boundary ADRs documented.
- [x] Attacker model established.
- [x] Privacy and safety invariants defined.
- [x] Data classification and retention strategy documented.
- [x] Legal response model scoped to metadata-only disclosures.
